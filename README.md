
# 📚 BookNest – Bookmark Manager

BookNest is a simple bookmark manager built with React and Supabase. It helps users save, organize, and manage their favorite website links in one place.

## ✨ Features
- User Signup and Login
- Add and Save Bookmarks
- View Personal Bookmarks
- Organize Bookmarks by Category
- Add and Remove Favorites
- Sign Out

## 🛠️ Technologies Used
- React.js
- JavaScript
- CSS
- Supabase
- React Router DOM
- SweetAlert2

## 🎯 About the Project

This project helped me practice React components, hooks, state management, routing, API integration, and Supabase authentication and database operations.
